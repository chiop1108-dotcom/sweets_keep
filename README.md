# SweetsKeep
## サイト概要
### サイトテーマ
スイーツの日持ち・持ち歩き時間・場所などを記録＆共有することのできるレビューサイト。 
​
### テーマを選んだ理由
スイーツが大好きで、和菓子・洋菓子職人の経験があり、食べ歩きも趣味でよく行うのですが、顧客側と販売・製造側を経験してみて、両者が「持ち歩き時間」と「賞味期限」についてとても気にしていることを実感しました。​お菓子好きの方、お手土産をお買い求めの方はそれに加えて「購入できるエリア」も重要視している印象がありました。

また、和菓子離れが進んでいるので生活で触れる機会を作りたいと思いました。

知り合いや仕事先へのお手土産探し、食べ歩きでの近くのお店探しに役立つ情報を共有できる場を作りたい、和菓子に少しでも興味を持つきっかけを作りたいと思い、このテーマにしました。

### ターゲットユーザ
- お手土産やお土産選びで「移動時間に耐えられるか」「日持ちはするか」「近くで購入できるところはあるか」に悩む人
- お菓子が好きでよく買いまわる人
​
### 主な利用シーン
- お手土産やお土産選びの時
- 食べ歩きや趣味でお菓子を近くで買いたい時
- 美味しくて甘いものを探したい時
